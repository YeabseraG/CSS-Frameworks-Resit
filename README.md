# Heavens Palate

A recipe website built with Bootstrap 5 and Sass for the CSS Frameworks assignment.

## Features

* Responsive recipe listing page
* Individual recipe page
* Admin dashboard
* HTML form validation
* Custom Bootstrap styling using Sass
* Responsive navigation for both mobile and desktop

## Technologies

* HTML5
* Bootstrap 5
* Sass

## Running the Project

Install dependencies:

npm install

Compile Sass:

npm run sass

Or watch for changes:

npm run watch
